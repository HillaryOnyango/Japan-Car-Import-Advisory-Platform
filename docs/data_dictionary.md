# Data Dictionary

| Column | Description |
|---|---|
| source_platform | Website where the listing was collected |
| listing_url | URL of the vehicle listing |
| make | Vehicle manufacturer |
| model | Vehicle model |
| year | Year of manufacture |
| mileage_km | Vehicle mileage in kilometers |
| engine_size_cc | Engine capacity in cubic centimeters |
| fuel_type | Petrol, diesel, hybrid, electric, etc. |
| transmission | Automatic or manual |
| body_type | SUV, sedan, hatchback, wagon, etc. |
| price_usd | Listing price in USD |
| price_kes | Listing price converted to KES |
