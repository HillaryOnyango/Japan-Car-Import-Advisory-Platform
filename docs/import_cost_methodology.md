# Import Cost Methodology

The platform estimates Kenya vehicle import cost using the following broad components:

1. Purchase price
2. Shipping cost
3. Insurance
4. CIF value
5. Import duty
6. Excise duty
7. VAT
8. Import Declaration Fee
9. Railway Development Levy
10. Port charges
11. Clearing fees
12. Registration costs
13. Other charges

> Note: Actual KRA valuation depends on official rules such as CRSP, depreciation rates, vehicle age limits, and applicable tax law. Verify official rates before production use.
